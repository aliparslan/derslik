## پاكىزلىقنىڭ ئىسلامدىكى ئەھمىيىتى ۋە سۇلارنىڭ تۈرلىرى (سوئال 205 – 216)

    <span class="qa-label">سوئال:</span>

    <div class="qa-footnotes" style="margin-top: 0.75rem; font-size: 0.85rem; opacity: 0.8;"><span>[ئىمام مۇسلىم رىۋايىتى]</span></div>

</div>

  <div class="qa-question">

  </div>
</div>

<div class="qa-card" id="q207">

  </div>
</div>

<div class="qa-card" id="q208">
  <div class="qa-question">

  </div>
</div>

<div class="qa-card" id="q209">

  </div>
</div>

<div class="qa-card" id="q210">
  <div class="qa-question">

</div>

</div>

</div>

</div>

  <div class="qa-question">

## ئىستىنجا، ئىستىبرا ۋە ھاجەتخانا ئەدەپلىرى (سوئال 217 – 224)

<div class="qa-card" id="q217">
  <div class="qa-question">
    <a href="#q217" class="qa-number-link" title="سوئال 217 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">217</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">ئىستىنجا دېگەن نېمە؟</span>
    <a href="#q217" class="qa-anchor" aria-label="سوئال 217 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> ئىستىنجا — كىچىك ياكى چوڭ تەرەت قىلغاندىن كېيىن تەرەت ئورۇنلىرىنى يۇيۇپ ياكى قۇرۇقداپ تازىلاش دېمەكتۇر.
  </div>
</div>

<div class="qa-card" id="q218">
  <div class="qa-question">
    <a href="#q218" class="qa-number-link" title="سوئال 218 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">218</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">ئىستىنجا قانچە تۈرلۈك بولىدۇ؟</span>
    <a href="#q218" class="qa-anchor" aria-label="سوئال 218 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> ئۈچ تۈرلۈك بولىدۇ: ئەتراپقا تارقالمىغان بولسا سۈرتۈپ تازىلاش سۈننەت؛ نىجاسەت تەڭگە مىقدارىدا تارقالسا سۇ بىلەن يۇيۇش ۋاجىب؛ تەڭگە مىقدارىدىن ئېشىپ كەتسە سۇ بىلەن يۇيۇش پەرز بولىدۇ.
  </div>
</div>

<div class="qa-card" id="q219">
  <div class="qa-question">
    <a href="#q219" class="qa-number-link" title="سوئال 219 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">219</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">ھەر قېتىم تاھارەت ئېلىش ئۈچۈن ئىستىنجا قىلىش شەرتمۇ؟</span>
    <a href="#q219" class="qa-anchor" aria-label="سوئال 219 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> ياق، تەرەت قىلمىغان (پەقەت يەل چىققان، ئۇخلىغان ياكى تېنى قانىغان) ئەھۋالدا ئىستىنجا قىلىش ھاجەتسىزدۇر. ئىستىنجا پەقەت تەرەت قىلغاندا قىلىنىدۇ.
  </div>
</div>

<div class="qa-card" id="q220">
  <div class="qa-question">
    <a href="#q220" class="qa-number-link" title="سوئال 220 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">220</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">ئىستىنجا قىلغاندا قانداق نەرسىلەرنى ئىشلىتىشكە بولىدۇ؟</span>
    <a href="#q220" class="qa-anchor" aria-label="سوئال 220 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> ئەڭ ياخشىسى سۇدۇر. سۇ يوق ئەھۋالدا چالما، پاكىز قەغەز ۋە تاش ئىشلەتسىمۇ بولىدۇ.
  </div>
</div>

<div class="qa-card" id="q221">
  <div class="qa-question">
    <a href="#q221" class="qa-number-link" title="سوئال 221 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">221</span></a>

  </div>
</div>

<div class="qa-card" id="q222">
  <div class="qa-question">
    <a href="#q222" class="qa-number-link" title="سوئال 222 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">222</span></a>

    <a href="#q222" class="qa-anchor" aria-label="سوئال 222 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>

  </div>
</div>

<div class="qa-card" id="q223">
  <div class="qa-question">

  </div>
</div>

## پايپاققا ۋە تېڭىققا مەسھى قىلىش ھەم ئۆزۈرلۈكلەر تاھارىتى (سوئال 242 – 248)

<div class="qa-card" id="q242">
  <div class="qa-question">
    <a href="#q242" class="qa-number-link" title="سوئال 242 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">242</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">ئاياققا ياكى پايپاققا مەسھى قىلىش دېگەن نېمە؟</span>
    <a href="#q242" class="qa-anchor" aria-label="سوئال 242 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> تاھارەت ئالغاندا پۇتلارنى يۇيۇشنىڭ ئورنىغا تاھارەت بىلەن كىيىلگەن مەسە، ئۆتۈك ياكى قېلىن پايپاق قاتارلىقلارنىڭ ئۈستىنى ھۆل قول بىلەن سىلاش دېگەنلىكتۇر.
  </div>
</div>

<div class="qa-card" id="q243">
  <div class="qa-question">
    <a href="#q243" class="qa-number-link" title="سوئال 243 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">243</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">ئاياققا ياكى پايپاققا مەسھى قىلىشنىڭ شەرتى نېمە؟</span>
    <a href="#q243" class="qa-anchor" aria-label="سوئال 243 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> (1) ئاياقنىڭ ئوشۇقنى يېپىپ تۇرىدىغان، پايپاقنىڭ قېلىن بولۇشى. (2) تاھارەت ئېلىپ بولغاندىن كېيىن كىيىلگەن بولۇشى. (3) پاسكىنىلىقتىن پاكىز بولۇشى. (4) جۇنۇپلۇقتىن خالىي بولۇشى. (5) مەسھى مۇددىتى ئىچىدە بولۇشى.
    <div class="qa-footnotes" style="margin-top: 0.75rem; font-size: 0.85rem; opacity: 0.8;"><span>[پايپاققا مەسھى قىلىش سەھىھ ھەدىسلەر بىلەن سابىت بولغان سۈننەتتۇر.]</span></div>
  </div>
</div>

<div class="qa-card" id="q244">
  <div class="qa-question">
    <a href="#q244" class="qa-number-link" title="سوئال 244 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">244</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">مەسھىنى قانداق قىلىش كېرەك؟</span>
    <a href="#q244" class="qa-anchor" aria-label="سوئال 244 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> قوللارنى ھۆل قىلىپ، ئوڭ قولنىڭ بارماقلىرى بىلەن ئوڭ پۇتنىڭ، سول قولنىڭ بارماقلىرى بىلەن سول پۇتنىڭ ئۇچىدىن ئوشۇق تەرەپكە بىر قېتىم سىلاشتۇر.
  </div>
</div>

<div class="qa-card" id="q245">
  <div class="qa-question">
    <a href="#q245" class="qa-number-link" title="سوئال 245 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">245</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">مەسھىنىڭ مۇددىتى قانچىلىك؟</span>
    <a href="#q245" class="qa-anchor" aria-label="سوئال 245 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> مۇقىملار ئۈچۈن بىر كېچە-كۈندۈز (24 سائەت)، يولۇچىلار ئۈچۈن ئۈچ كېچە-كۈندۈز (72 سائەت) تۇر.
  </div>
</div>

<div class="qa-card" id="q246">
  <div class="qa-question">
    <a href="#q246" class="qa-number-link" title="سوئال 246 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">246</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">مەسھىنى بۇزىدىغان ئامىللار قايسىلار؟</span>
    <a href="#q246" class="qa-anchor" aria-label="سوئال 246 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> (1) تاھارەتنى بۇزىدىغان ئامىللار. (2) پۇتنىڭ ئاياقتىن ياكى پايپاقتىن چىقىشى. (3) مەسھى مۇددىتىنىڭ تۈگىشى. (4) سۇ ئۆتۈپ پۇتنىڭ ھۆل بولۇپ كېتىشى.
  </div>
</div>

<div class="qa-card" id="q247">
  <div class="qa-question">
