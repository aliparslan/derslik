## غۇسلىنىڭ پەرزلىرى، سۈننەتلىرى ۋە تەرتىپى (سوئال 260 – 268)

<div class="qa-card" id="q260">
  <div class="qa-question">
    <a href="#q260" class="qa-number-link" title="سوئال 260 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">260</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">غۇسلى دېگەن نېمە؟</span>
    <a href="#q260" class="qa-anchor" aria-label="سوئال 260 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> پاكلىنىش نىيىتى بىلەن پۈتۈن بەدەننى يۇيۇش ئارقىلىق ئومۇمىي چوڭ تازىلىق قىلىشتۇر.
  </div>
</div>

<div class="qa-card" id="q261">
  <div class="qa-question">
    <a href="#q261" class="qa-number-link" title="سوئال 261 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">261</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">غۇسلى قىلىشنى كېرەك قىلىدىغان ئىشلار قايسىلار؟</span>
    <a href="#q261" class="qa-anchor" aria-label="سوئال 261 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> (1) جىنسىي مۇناسىۋەت ئۆتكۈزۈش (ئىسپېرما چىقمىسىمۇ غۇسلى پەرز). (2) ئىسپېرمىنىڭ ئېتىلىپ چىقىشى. (3) ئۇيقۇدا ئىھتىلام بولۇش. (4) تۇغۇت ۋە ئايلىق ئادەت قانلىرى توختاش. (5) ھوشسىزلىقتىن ئېسىگە كەلگەندە ئىسپېرما ئەسىرىنى كۆرۈش.
  </div>
</div>

<div class="qa-card" id="q262">
  <div class="qa-question">
    <a href="#q262" class="qa-number-link" title="سوئال 262 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">262</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">غۇسلى قانچە تۈرلۈك بولىدۇ؟</span>
    <a href="#q262" class="qa-anchor" aria-label="سوئال 262 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> ئۈچ تۈرلۈك بولىدۇ: پەرز غۇسلى، سۈننەت غۇسلى ۋە مۇستەھەب غۇسلى.
  </div>
</div>

<div class="qa-card" id="q263">
  <div class="qa-question">
    <a href="#q263" class="qa-number-link" title="سوئال 263 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">263</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">پەرز بولغان غۇسلى قايسى؟</span>
    <a href="#q263" class="qa-anchor" aria-label="سوئال 263 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> غۇسلى قىلىشنى كېرەك قىلىدىغان بەش سەۋەبنىڭ بىرى يۈز بەرگەندىن كېيىن قىلىنىدىغان غۇسلىدۇر.
  </div>
</div>

<div class="qa-card" id="q264">
  <div class="qa-question">
    <a href="#q264" class="qa-number-link" title="سوئال 264 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">264</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">سۈننەت بولغان غۇسلى قايسىلار؟</span>
    <a href="#q264" class="qa-anchor" aria-label="سوئال 264 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> (1) جۈمە نامىزى ئۈچۈن. (2) ھېيت نامازلىرى ئۈچۈن. (3) ھەج ياكى ئۆمرىگە ئېھرام باغلاش ئۈچۈن. (4) ئەرەفاتتا تۇرۇش ئۈچۈن غۇسلى قىلىشتۇر.
  </div>
</div>

<div class="qa-card" id="q265">
  <div class="qa-question">
    <a href="#q265" class="qa-number-link" title="سوئال 265 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">265</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">مۇستەھەب بولغان غۇسلى قايسىلار؟</span>
    <a href="#q265" class="qa-anchor" aria-label="سوئال 265 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> مەسجىدى ھەرەم ۋە مەسجىدى نەبەۋىيگە كىرىش، مۇزدەلىفىدە تۇرۇش، مېيىتنى يۇغاندىن كېيىن، قان ئالدۇرغاندىن كېيىن، ھوشىغا كەلگەندىن كېيىن، ۋە يېڭى مۇسۇلمان بولغاندا غۇسلى قىلىشتۇر.
  </div>
</div>

<div class="qa-card" id="q266">
  <div class="qa-question">
    <a href="#q266" class="qa-number-link" title="سوئال 266 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">266</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">غۇسلىنىڭ پەرزى قانچە؟</span>
    <a href="#q266" class="qa-anchor" aria-label="سوئال 266 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> ئۈچ تۈرلۈك: (1) ئېغىزغا سۇ ئېلىپ چايقاش. (2) بۇرۇنغا سۇ ئېلىپ تازىلاش. (3) پۈتۈن بەدەننى قۇرۇق يەر قالدۇرماي يۇيۇش.
  </div>
</div>

<div class="qa-card" id="q267">
  <div class="qa-question">
    <a href="#q267" class="qa-number-link" title="سوئال 267 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">267</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">غۇسلىنىڭ سۈننەتلىرى قايسىلار؟</span>
    <a href="#q267" class="qa-anchor" aria-label="سوئال 267 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> نىيەت قىلىش، بىسمىللاھ دېيىش، ئىككى قولنى بىلەكلەرگىچە يۇيۇش، بەدەندىكى نىجاسەتنى تازىلاش، تاھارەت ئېلىش ۋە بەدەننى ئۈچ قېتىمدىن سۇ قۇيۇپ يۇيۇشتۇر.
  </div>
</div>

<div class="qa-card" id="q268">
  <div class="qa-question">
    <a href="#q268" class="qa-number-link" title="سوئال 268 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">268</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">غۇسلى قىلىشنىڭ قائىدە-تەرتىبى قانداق؟</span>
    <a href="#q268" class="qa-anchor" aria-label="سوئال 268 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> ئاۋۋال نىيەت قىلىپ بىسمىللاھ دەيمىز، قوللارنى يۇيۇپ ئەۋرەت ئەزانى پاكىزلايمىز، ئاندىن نامازغا تاھارەت ئالغاندەك تاھارەت ئالىمىز، ئاندىن باشقا ۋە بەدەنگە سۇ قۇيۇپ پۈتۈن بەدەننى ئۇۋۇلاپ يۇيىمىز.
  </div>
</div>

## تەيەممۇمنىڭ شەرتلىرى، پەرزلىرى ۋە تەرتىپى (سوئال 269 – 274)

<div class="qa-card" id="q269">
  <div class="qa-question">
    <a href="#q269" class="qa-number-link" title="سوئال 269 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">269</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">تەيەممۇم دېگەن نېمە؟</span>
    <a href="#q269" class="qa-anchor" aria-label="سوئال 269 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> سۇ يوق ياكى سۇ ئىشلىتىش مۇمكىن بولمىغاندا، پاكىز تۇپراق جىنسى بىلەن تاھارەت ياكى غۇسلى ئورنىدا پاكلىق ھاسىل قىلىشتۇر.
  </div>
</div>

<div class="qa-card" id="q270">
  <div class="qa-question">
    <a href="#q270" class="qa-number-link" title="سوئال 270 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">270</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">تەيەممۇمنى كېرەك قىلىدىغان سەۋەبلەر قايسىلار؟</span>
    <a href="#q270" class="qa-anchor" aria-label="سوئال 270 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> (1) يېتەرلىك سۇ تاپالمىغاندا. (2) سۇ بىر مىل ياكى ئۇنىڭدىن يىراقتا بولسا. (3) كېسەل بولۇش ياكى ئېغىرلىشىشتىن قورققاندا. (4) تەشنا بولۇپ قېلىشتىن قورققاندا. (5) قاتتىق سوغۇقتا سۇ زىيان قىلىدىغان بولسا. (6) جىنازا ياكى ھېيت نامىزىغا ئۈلگۈرەلمەسلىكتىن قورققاندا.
  </div>
</div>

<div class="qa-card" id="q271">
  <div class="qa-question">
    <a href="#q271" class="qa-number-link" title="سوئال 271 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">271</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">تەيەممۇمنىڭ پەرزى قانچە؟</span>
    <a href="#q271" class="qa-anchor" aria-label="سوئال 271 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> تۆت تۈرلۈكتۇر: (1) پاك تۇپراق تېپىش. (2) نىيەت قىلىش. (3) يۈزنى سىلاش. (4) ئىككى قولنى جەينەكلىرى بىلەن قوشۇپ سىلاش.
  </div>
</div>

<div class="qa-card" id="q272">
  <div class="qa-question">
    <a href="#q272" class="qa-number-link" title="سوئال 272 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">272</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">تەيەممۇمنىڭ سۈننەتلىرى قانچە؟</span>
    <a href="#q272" class="qa-anchor" aria-label="سوئال 272 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> بىسمىللاھ دەپ باشلاش، بارماقلارنى ئېچىپ ئۇرۇش، تۇپراقنى سىلكىۋېتىش، تەرتىپ ۋە ئارقىمۇ-ئارقىلىققا رىئايە قىلىشتۇر.
  </div>
</div>

<div class="qa-card" id="q273">
  <div class="qa-question">
    <a href="#q273" class="qa-number-link" title="سوئال 273 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">273</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">تەيەممۇمنىڭ قائىدىسى قانداق؟</span>
    <a href="#q273" class="qa-anchor" aria-label="سوئال 273 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> نىيەت قىلىپ بىسمىللاھ دەيمىز. ئالقاننى پاكىز تۇپراققا بىر ئۇرۇپ سىلكىپ يۈزىمىزنى سىلايمىز. ئىككىنچى قېتىم ئۇرۇپ ئىككى قولنى جەينەكلەرگىچە سىلايمىز.
  </div>
</div>

<div class="qa-card" id="q274">
  <div class="qa-question">
    <a href="#q274" class="qa-number-link" title="سوئال 274 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">274</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">تەيەممۇمنى بۇزىدىغان ئامىللار قايسىلار؟</span>
    <a href="#q274" class="qa-anchor" aria-label="سوئال 274 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> (1) تاھارەتنى بۇزىدىغان ھەر قانداق نەرسە. (2) سۇ تېپىلىشى. (3) سۇ ئىشلىتىشكە توسالغۇ بولغان ئۈزۈرنىڭ يوقىلىشى.
  </div>
</div>
