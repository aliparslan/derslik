## ھەيز ۋە نىپاس ئەھكاملىرى (سوئال 249 – 255)

<div class="qa-card" id="q249">
  <div class="qa-question">
    <a href="#q249" class="qa-number-link" title="سوئال 249 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">249</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">ئاياللارغا خاس قانچە ھالەت بار؟</span>
    <a href="#q249" class="qa-anchor" aria-label="سوئال 249 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> ئۈچ خىل ھالەت بار: (1) ئايلىق ھالىتى (ھەيز). (2) تۇغۇتلۇق ھالىتى (نىفاس). (3) ئۈزۈرلۈك ھالىتى (مۇستەھازە).
  </div>
</div>

<div class="qa-card" id="q250">
  <div class="qa-question">
    <a href="#q250" class="qa-number-link" title="سوئال 250 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">250</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">ئاياللارنىڭ ئايلىق ھالىتى دېگەن نېمە؟</span>
    <a href="#q250" class="qa-anchor" aria-label="سوئال 250 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> ئادەت كۆرۈش يېشىدىكى ئاياللارنىڭ بالىياتقۇسىدىن نورمال كېلىدىغان قېنىدۇر.
  </div>
</div>

<div class="qa-card" id="q251">
  <div class="qa-question">
    <a href="#q251" class="qa-number-link" title="سوئال 251 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">251</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">ئاياللارنىڭ ئايلىق ئادىتىنىڭ مۇددىتى قانچىلىك؟</span>
    <a href="#q251" class="qa-anchor" aria-label="سوئال 251 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> ئەڭ ئاز بولغاندا ئۈچ كۈن، ئەڭ كۆپ بولغاندا ئون كۈن بولىدۇ، نورمالدا بەش كۈندىن يەتتە كۈنگىچەدۇر.
  </div>
</div>

<div class="qa-card" id="q252">
  <div class="qa-question">
    <a href="#q252" class="qa-number-link" title="سوئال 252 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">252</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">ئاياللارنىڭ تۇغۇتلۇق ھالىتى دېگەن نېمە؟</span>
    <a href="#q252" class="qa-anchor" aria-label="سوئال 252 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> تۇغۇتتىن كېيىن تۇغۇت قېنىدىن پاكلانغىچە بولغان مەزگىلدۇر (نىفاس).
  </div>
</div>

<div class="qa-card" id="q253">
  <div class="qa-question">
    <a href="#q253" class="qa-number-link" title="سوئال 253 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">253</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">ئاياللارنىڭ تۇغۇتلۇق ھالىتىنىڭ مۇددىتى قانچىلىك؟</span>
    <a href="#q253" class="qa-anchor" aria-label="سوئال 253 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> ئەڭ كۆپ بولغاندا 40 كۈندۇر. قىرىق كۈندىن ئېشىپ كەتكىنى ئۈزۈر ھېسابلىنىدۇ.
  </div>
</div>

<div class="qa-card" id="q254">
  <div class="qa-question">
    <a href="#q254" class="qa-number-link" title="سوئال 254 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">254</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">ئاياللار ئادەت كۆرگەن ياكى تۇغۇتتىن كېيىنكى قېنىدىن پاكلىنىپ بولمىغان ۋاقىتلىرىدا قانداق ئىشلارنى قىلمايدۇ؟</span>
    <a href="#q254" class="qa-anchor" aria-label="سوئال 254 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> (1) ناماز ئوقۇش. (2) روزا تۇتۇش. (3) قۇرئان تۇتۇش ۋە ئوقۇش. (4) مەسجىدكە كىرىش. (5) تىلاۋەت سەجدىسى. (6) ئېتىكاپ. (7) كەبىنى تاۋاپ قىلىش. (8) جىنسىي مۇناسىۋەت قىلىش.
  </div>
</div>

<div class="qa-card" id="q255">
  <div class="qa-question">
    <a href="#q255" class="qa-number-link" title="سوئال 255 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">255</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">ئاياللار يۇقىرىقى ھالەتلىرىدە قىلالمىغان ئىبادەتلىرىنى قانداق قىلىدۇ؟</span>
    <a href="#q255" class="qa-anchor" aria-label="سوئال 255 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> نامازنىڭ قازاسىنى قىلمايدۇ، چۈنكى ناماز ساقىت بولىدۇ. روزىنىڭ قازاسىنى كېيىن تۇتۇپ بېرىدۇ.
  </div>
</div>

## ئىستىھازە ۋە تاھارەتسىز چەكلەنگەن ئىشلار (سوئال 256 – 259)

<div class="qa-card" id="q256">
  <div class="qa-question">
    <a href="#q256" class="qa-number-link" title="سوئال 256 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">256</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">ئاياللارنىڭ ئۈزۈرلۈك ھالىتى دېگەن نېمە؟</span>
    <a href="#q256" class="qa-anchor" aria-label="سوئال 256 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> ئادەت كۈنلىرىدىن ئارتۇق (10 كۈندىن ئاشقان ياكى 3 كۈنگە يەتمىگەن)، تۇغۇتتا 40 كۈندىن ئاشقان قان ئۈزۈرلۈك ھالەت (مۇستەھازە) ھېسابلىنىدۇ.
  </div>
</div>

<div class="qa-card" id="q257">
  <div class="qa-question">
    <a href="#q257" class="qa-number-link" title="سوئال 257 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">257</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">ئۈزۈرلۈك ھالىتىدىكى ئاياللار ئىبادەتلەرنى قىلالامدۇ؟</span>
    <a href="#q257" class="qa-anchor" aria-label="سوئال 257 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> ئىبادەتلەرنى تولۇق قىلىدۇ، ھەر ۋاخ ئۈچۈن ئايرىم تاھارەت ئېلىپ ناماز ئوقۇيدۇ ۋە روزا تۇتىدۇ.
  </div>
</div>

<div class="qa-card" id="q258">
  <div class="qa-question">
    <a href="#q258" class="qa-number-link" title="سوئال 258 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">258</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">تاھارەتسىز كىشىلەر ئۈچۈن مەنئى قىلىنغان ئىشلار قايسىلار؟</span>
    <a href="#q258" class="qa-anchor" aria-label="سوئال 258 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> (1) ناماز ئوقۇش. (2) قۇرئان تۇتۇش. (3) كەبىنى تاۋاپ قىلىش.
  </div>
</div>

<div class="qa-card" id="q259">
  <div class="qa-question">
    <a href="#q259" class="qa-number-link" title="سوئال 259 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">259</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">جۇنۇپ كىشى ئۈچۈن مەنئى قىلىنغان ئىشلار قايسىلار؟</span>
    <a href="#q259" class="qa-anchor" aria-label="سوئال 259 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> تاھارەتسىزگە مەنئى قىلىنغان ئىشلاردىن سىرت، قۇرئاننى يادقا بولسىمۇ ئوقۇش، مەسجىدكە كىرىش ۋە ئۇنىڭدا ئولتۇرۇش مەنئى قىلىنىدۇ.
  </div>
</div>
