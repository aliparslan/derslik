## قىيامەت كۈنىگە ئىمان ۋە قايتا تىرىلىش دەلىللىرى (سوئال 135 – 140)

<div class="qa-card" id="q135">
  <div class="qa-question">
    <a href="#q135" class="qa-number-link" title="سوئال 135 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">135</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">قىيامەت كۈنى دېگەن قانداق كۈن؟</span>
    <a href="#q135" class="qa-anchor" aria-label="سوئال 135 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> بۇ دۇنيا پۈتۈنلەي تۈگەپ يوق بولغاندىن كېيىن، ئاخىرەت ناملىق يېڭى، مەڭگۈلۈك ھايات باشلىنىدىغان كۈندۇر.
  </div>
</div>

<div class="qa-card" id="q136">
  <div class="qa-question">
    <a href="#q136" class="qa-number-link" title="سوئال 136 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">136</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">قىيامەت كۈنىدە قانداق ئىشلار بولىدۇ؟</span>
    <a href="#q136" class="qa-anchor" aria-label="سوئال 136 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> ئىنسانلار قايتا تىرىلىپ، ھېساب مەيدانىغا يىغىلىدۇ، دۇنيادىكى بارلىق ئەمەللىرىدىن تەپسىلىي ھېساب بېرىدۇ ۋە زەررىچە ياخشى-يامان ئىشنىڭ جازا-مۇكاپاتىنى كۆرىدۇ.
  </div>
</div>

<div class="qa-card" id="q137">
  <div class="qa-question">
    <a href="#q137" class="qa-number-link" title="سوئال 137 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">137</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">قىيامەت كۈنىگە قانداق ئىمان كەلتۈرۈش كېرەك؟</span>
    <a href="#q137" class="qa-anchor" aria-label="سوئال 137 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> ئۆلگەندىن كېيىن قايتا تىرىلىش، قەبىردىكى سوراق، ھېساب بېرىش، مىزان، سىرات، جەننەت ۋە دوزاخنىڭ ھەق ۋە راست ئىكەنلىكىگە چىن كۆڭلىدىن ئىشىنىش كېرەك.
  </div>
</div>

<div class="qa-card" id="q138">
  <div class="qa-question">
    <a href="#q138" class="qa-number-link" title="سوئال 138 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">138</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">قىيامەت كۈنىگە ئىمان كەلتۈرۈش نېمىلەرنى ئۆز ئىچىگە ئالىدۇ؟</span>
    <a href="#q138" class="qa-anchor" aria-label="سوئال 138 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> (1) قىيامەت كۈنىدىكى پۈتۈن ھادىسىلەرگە ۋە جەننەت-دوزاخقا ئىشىنىش. (2) قەبىر ئالىمىگە (بەرزەخكە) — مېيىتنىڭ سوراق قىلىنىشى ۋە قەبىر نېمىتى ياكى ئازابىغا ئىشىنىش.
  </div>
</div>

<div class="qa-card" id="q139">
  <div class="qa-question">
    <a href="#q139" class="qa-number-link" title="سوئال 139 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">139</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">قىيامەت كۈنىگە ئىمان كەلتۈرۈشنىڭ پايدىلىرى قايسىلار؟</span>

  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> (1) ئاخىرەتلىك ساۋابنى كۆزلەپ ياخشى ئەمەللەرگە ئالدىراش. (2) ئازابتىن قورقۇپ گۇناھلاردىن يىراق تۇرۇش. (3) دۇنيادىكى زۇلۇم ۋە جاپالارغا سەۋر قىلىپ، ھەقىقىي ئادالەتنىڭ ئاخىرەتتە بارلىقىغا ئىشىنىپ خاتىرجەم بولۇش.
  </div>
</div>

<div class="qa-card" id="q140">
  <div class="qa-question">
    <a href="#q140" class="qa-number-link" title="سوئال 140 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">140</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">ئۆلگەندىن كېيىنكى تىرىلىشكە ئىنكار قىلغۇچىلارغا قانداق رەددىيە بېرىلىدۇ؟</span>
    <a href="#q140" class="qa-anchor" aria-label="سوئال 140 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> نەقلىي، ئەقلىي ۋە ھېسسىي دەلىللەر بىلەن رەت قىلىنىدۇ: يوقتىن ياراتقان ئاللاھ ئەلۋەتتە قايتا يارىتىشقا قادىردۇر; قاقاس، ئۆلۈك زېمىننى يامغۇر بىلەن تىرىلدۈرگەن زات ئۆلۈكلەرنىمۇ تىرىلدۈرۈشكە قادىردۇر.
    <div class="qa-footnotes" style="margin-top: 0.75rem; font-size: 0.85rem; opacity: 0.8;"><span>[رۇم سۈرىسى 27-ئايەت]</span> <span>[فۇسسىلەت سۈرىسى 39-ئايەت]</span></div>
  </div>
</div>

## قىيامەتنىڭ كىچىك ۋە چوڭ ئالامەتلىرى (سوئال 141 – 142)

  <div class="qa-question">

    <span class="qa-label">سوئال:</span>
    <span class="qa-text">قىيامەت قاچان بولىدۇ؟</span>
    <a href="#q141" class="qa-anchor" aria-label="سوئال 141 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> قىيامەتنىڭ ۋاقتىنى ئاللاھتىن باشقا ھېچكىم بىلمەيدۇ، ئۇ يالغۇز ئاللاھقىلا خاس غەيبىي ئىلىمدۇر.
    <div class="qa-footnotes" style="margin-top: 0.75rem; font-size: 0.85rem; opacity: 0.8;"><span>[ئەئراف سۈرىسى 187-ئايەت]</span></div>
  </div>
</div>

<div class="qa-card" id="q142">
  <div class="qa-question">
    <a href="#q142" class="qa-number-link" title="سوئال 142 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">142</span></a>
    <span class="qa-label">سوئال:</span>
    <span class="qa-text">قىيامەتنىڭ ئالامەتلىرى قايسىلار؟</span>
    <a href="#q142" class="qa-anchor" aria-label="سوئال 142 نىڭ بىۋاسىتە ئۇلىنىشى" title="بىۋاسىتە ئۇلىنىش">#</a>
  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> كىچىك ئالامەتلەر: نادانلىقنىڭ ئېشىشى، ھاراق ۋە زىنانىڭ ئەۋج ئېلىشى، تەبىئىي بايلىقلارنى ئىسراپ قىلىش قاتارلىقلار؛ چوڭ ئالامەتلەر: دەججالنىڭ چىقىشى، ئىسا ئەلەيھىسسالامنىڭ چۈشۈشى، قۇياشنىڭ غەربتىن چىقىشى قاتارلىقلار.
  </div>
</div>

## قەبرە ھاياتى، بەرزەخ ئالىمى ۋە روھلارنىڭ قارارگاھى (سوئال 143 – 148)

<div class="qa-card" id="q143">
  <div class="qa-question">
    <a href="#q143" class="qa-number-link" title="سوئال 143 گە بىۋاسىتە ئۇلىنىش"><span class="qa-number">143</span></a>

  </div>
  <div class="qa-answer">
    <span class="qa-label">جاۋاب:</span> مۇنكەر ۋە نەكىر ئىسىملىك ئىككى پەرىشتە: «رەببىڭ كىم؟ دىنىڭ نېمە؟ پەيغەمبىرىڭ كىم؟» دەپ سورايدۇ. مۆمىن ئادەم توغرا جاۋاب بېرىپ نېئمەتكە ئېرىشىدۇ، كاپىر ۋە مۇناپىق جاۋاب بېرەلمەي ئازابقا ئۇچرايدۇ.
  </div>
</div>

<div class="qa-card" id="q144">

</div>

## قىيامەت كۈنىدىكى سوت، ھېساب، مىزان ۋە سىرات (سوئال 149 – 160)

  <div class="qa-answer">

</div>
