## ئاللاھ تائالانىڭ 99 گۈزەل ئىسمى

| ئەرەبچە نامى | ئۇيغۇرچە ئوقۇلۇشى | مەنىسى |
| :--- | :--- | :--- |
| اللهُ | ئاللاھ | بارچە مەۋجۇداتنىڭ يېگانە ئىگىسى، ئىبادەتكە ۋە بويسۇنۇشقا ھەقلىق بولغان ئىلاھىي مەبۇدنىڭ ئىسمى. |
| الرَّحْمَنُ | ئەررەھمان | ئاللاھنىڭ پۈتۈن مەخلۇقاتلىرى ئۈچۈن رەھمىتىنىڭ كەڭلىكى ۋە شامىللىقىغا دالالەت قىلىدىغان ئىسىم، بولۇپ ئاللاھتىن باشقىسىغا ئىشلىتىلمەيدىغان خاس ئىسىمدۇر. |
| الرَّحِيمُ | ئەررەھىيم | مۈمىنلەرگە بۇ دۇنيا ۋە ئاخىرەتتە شەپقەت-رەھىم قىلغۇچى دېگەن مەنىدە، بولۇپ ئاللاھنىڭ مۈمىنلەرنى بۇ دۇنيادا ئىسلامغا ھىدايەت قىلغانلىقى ۋە ئاخىرەتتە جەننەت بىلەن مۇكاپاتلايدىغانلىقى ئۇنىڭ رەھىم سۈپىتىنىڭ تەقەززاسىدۇر. |
| العَفُوُّ | ئەل ئەفۋۇ | جازاغا ھەقلىق بولغانلاردىن خالىغان كىشىلەرنىڭ گۇناھىنى، خاتالىقىنى كەچۈرگۈچى، جازادىن ئەپۇ قىلغۇچى دېگەن مەنىدە. |
| الغَفُورُ | ئەل غەفۇر | گۇناھ قىلغۇچىنى رەسۋا قىلماستىن گۇناھىنى يۈگۈگۈچى ۋە جازادىن ئەپۇ قىلغۇچى ئاللاھتۇر. |
| الغَفَّارُ | ئەل غەففار | ئاللاھنىڭ بەندىلەرنى ناھايىتى مەغپىرەت قىلغۇچى زات ئىكەنلىكىنى ئىپادىلەيدىغان ئىسمى. |
| الرَّؤُوفُ | ئەررەئۇف | رەھمەتنىڭ ۋە شەپقەتنىڭ كامالىتى بولغان سۈپەت، بولۇپ بۇ دۇنيادا پۈتۈن مەخلۇقات ئۈچۈن ئومۇم، ئاخىرەتتە ئاللاھنىڭ مۈمىن بەندىلىرى ئۈچۈن خاس بولغان رەھمەتنىڭ ئەڭ يۇقىرى ئىپادىسىنى بىلدۈرىدىغان ئىسىم. |
| الحَلِيمُ | ئەل ھەلىيم | كۈچى يېتىدىغان تۇرۇپ گۇناھكارلارنى ئالدىراپ جازالىمايدىغان، بەلكى تەۋبە قىلغۇچىلارنىڭ گۇناھلىرىنى ئەپۇ قىلىپ كەچۈرۈۋەتكۈچى ئاللاھتۇر. |
| التَّوَّابُ | ئەتتەۋۋاب | خالىغان بەندىلىرىنى تەۋبە قىلىشقا مۇۋەپپەق قىلغۇچى ۋە تەۋبىلەرنى قوبۇل قىلغۇچى ئاللاھتۇر. |
| السِّتِّيرُ | ئەسسىتتىير | بەندىلىرىنىڭ ئېيىبلىرىنى، خاتالىقلىرىنى، گۇناھلىرىنى ئىنسانلار ئارىسىدا ئاچماستىن يۈگىگۈچى دېگەن مەنىدە. |
| الغَنِيُّ | ئەل غەنىي | مۇتلەق تەڭداشسىز كامالەتكە ۋە قۇدرەتكە ئىگە بولغانلىقتىن، بەندىلىرىدىن ھېچبىرىگە مۇھتاج بولمىغان، پۈتۈن مەخلۇقات ئۇنىڭغا مۇھتاج بولغان زات. |
| الكَرِيمُ | ئەل كەرىم | ياخشىلىقى كۆپ، ئېھسانى مول، خالىغان بەندىسىگە سورىسۇن ياكى سورىمىسۇن خالىغانچە بېرىدىغان زات. |
| الأَكْرَمُ | ئەل ئەكرەم | سېخىيلىقتا، ئېھسان-ئاتا قىلىشتا تەڭدىشى يوق، ياخشىلىق پەقەت ئۇنىڭ قولىدا بولغان زات. |
| الوَهَّابُ | ئەل ۋەھھاب | كۆپ بەرگۈچى، بەدەلسىز بەرگۈچى ۋە سورىمىسىمۇ ئېھسان-ئاتا قىلغۇچى زات. |
| الجَوَادُ | ئەل جەۋۋاد | ھېسابسىز بەرگۈچى، بەندىلىرىگە ئېھسان-پەزلى قىلغۇچى، مۈمىنلەرگە تېخىمۇ كۆپ بەرگۈچى زات. |
| الوَدُودُ | ئەل ۋەدۇد | ھەقىقىي مۈمىن بەندىلىرىنى ياخشى كۆرىدىغان، ئۇلارغا ئەڭ ئالىي مۇكاپاتلارنى بېرىدىغان شەپقەتلىك زات. |
| المُعْطِي | ئەل مۇئتىي | خالىغان بەندىسىگە ياخشىلىق خەزىنىلىرىدىن ھېسابسىز بەرگۈچى، مۈمىنلەرگە مەنىۋى بايلىقتىن نېسىۋە بەرگۈچى زات. |
| الوَاسِعُ | ئەل ۋاسىئ | ياخشىلىقى كۆپ، ئېھسانى سانسىز، مەغپىرىتى كەڭ، شەپقىتى چەكسىز زات. |
| المُحْسِنُ | ئەلمۇھسىن | زاتىدا، سۈپەتلىرىدە، ئىسىملىرىدا كامالىيەتنىڭ ئەڭ يۇقىرى پەللىسى بولغان، ھەمىشە ياخشىلىق ئاتا قىلىدىغان زات. |
| الرَّازِقُ | ئەررازىق | پۈتۈن خەلقىگە رىزىق بەرگۈچى، مەخلۇقاتنى رىزىقلاندۇرۇشنى ئۆز ئۈستىگە ئالغان زات. |
| الرَّزَّاقُ | ئەررەززاق | ئاللاھنىڭ پۈتۈن مەخلۇقاتلىرىنى ھەمىشە رىزىقلاندۇرۇپ تۇرىدىغانلىقىنى ئىپادىلەيدىغان ئىسىم. |
| اللَّطِيفُ | ئەللەتىف | ئىشلارنىڭ ۋە شەيئىلەرنىڭ ئىنچىكە تەرەپلىرىنى بىلگۈچى، ياخشىلىقلارنى بەندىلىرىگە ئۇلار ھېس قىلمىغان شەكىلدە يەتكۈزۈپ بەرگۈچى زات. |
| الخَبِيرُ | ئەل خەبىير | شەيئىلەرنىڭ يوشۇرۇن تەرەپلىرىنى تولۇق بىلگۈچى، ئىلمى ھەممىنى ئۆز ئىچىگە ئالغۇچى زات. |
| الفَتَّاحُ | ئەل فەتتاھ | ياخشىلىق خەزىنىلىرىدىن رەھمىتىدىن ۋە رىزقىدىن خالىغانچە ئاچىدىغان ۋە بەندىلىرىنى تەمىنلەيدىغان زاتتۇر. |
| العَلِيمُ | ئەل ئەلىيم | شەيئىلەرنىڭ ئاشكارا ۋە يوشۇرۇن پۈتۈن تەرەپلىرىنى تەپسىلىي ۋە ئېنىق بىلگۈچى، كەلگۈسى ئىشلارنى بىلگۈچى زاتتۇر. |
| البَرُّ | ئەل بەررۇ | بەندىلىرىگە ۋە جىمى مەخلۇقاتلىرىغا ئېھسان قىلىشتا قولى كەڭ، بەرگەنلىرىنى ھېچكىم ساناپ بولالمايدىغان زاتتۇر. |
| الحَكِيمُ | ئەل ھەكىيم | ھەر ئىشنى ھېكمەت بىلەن جايىدا قىلغۇچى، قىلغانلىرىدا ھېچقانداق ناقىسلىق ياكى زىيادىلىك بولمايدىغان زاتتۇر. |
| الحَكَمُ | ئەل ھەكەم | بەندىلىرىنىڭ ئوتتۇرىسىدا ئادالەت بىلەن ھۆكۈم قىلىدىغان، ھېچكىمگە قىلچە ھەقسىزلىق قىلمايدىغان زاتتۇر. |
| الشَّاكِرُ | ئەل شاكىر | ئىتائەت قىلغۇچىلارنى ماختايدىغان، ئاز ئەمەلگە كۆپ ساۋاب بېرىدىغان، نېمەتكە شۈكۈر قىلغۇچىلارغا زىيادە قىلىپ بەرگۈچى زاتتۇر. |
| الشَّكُورُ | ئەل شەكۇر | بەندىلەرنىڭ ئاز ئەمەللىرىنى كۆپ قىلىپ قوبۇل قىلىدىغان، مۇكاپاتىنى ھەسسىلەپ بېرىدىغان زاتتۇر. |
| الجَمِيلُ | ئەل جەمىيل | زاتىدا، ئىسىم-سۈپەتلىرىدە ۋە پۈتۈن ئىشلىرىدا گۈزەل، بارچە گۈزەللىكلەرنىڭ مەنبەسى بولغان زاتتۇر. |
| المَجِيدُ | ئەل مەجىيد | ئاسمانلار ۋە زېمىندىكى مۇتلەق ئىپتىخار، ئىززەت ۋە قەدىر-قىممەتكە سازاۋەر بولغان زاتتۇر. |
| الوَلِيُّ | ئەل ۋەلىي | مەخلۇقاتىنىڭ ئىشلىرىنى باشقۇرغۇچى، مۈمىنلەرگە ياردەم ۋە نۇسرەت بەرگۈچى زاتتۇر. |
| الحَمِيدُ | ئەل ھەمىيد | زاتى، ئىسىم-سۈپەتلىرى ۋە پۈتۈن ئىشلىرى ماختالغۇچى، ماختاشقا ۋە شۈكۈر قىلىشقا ھەقىقىي ھەقلىق بولغۇچى زاتتۇر. |
| المَوْلَى | ئەل مەۋلا | پەرۋىشكار، پادىشاھ، خوجايىن، مۈمىنلەرنى قوللىغۇچى ۋە ئۇلارغا ياردەم قىلغۇچى زاتتۇر. |
| النَّصِيرُ | ئەننەسىير | ياردىمى بىلەن خالىغان بەندىسىنى قوللىغۇچى، ھەمىشە ھەممىگە غالىب كەلگۈچى زاتتۇر. |
| السَّمِيعُ | ئەسسەمىئ | ھەر قانداق چاقىرىق، دۇئا ۋە مۇناجاتلارنى ئاڭلاپ تۇرغۇچى، تىلىگەنلىرىنى بەرگۈچى زاتتۇر. |
| البَصِيرُ | ئەل بەسىير | يوشۇرۇن ۋە ئاشكارا ئالەملەردىكى پۈتۈن شەيئىلەرنى ۋە ھەرىكەتلەرنى ناھايىتى ئېنىق كۆرگۈچى زاتتۇر. |
| الشَّهِيدُ | ئەشھەھىيد | بەندىلىرىنى كۆزەتكۈچى، ئۆزىنىڭ يېگانە ئىلاھ ئىكەنلىكىگە، ئادالەت بىلەن ئىش قىلىدىغانلىقىغا گۇۋاھ بولغۇچى زاتتۇر. |
| الرَّقِيبُ | ئەررەقىيب | بەندىلەرنىڭ ئاشكارا ۋە يوشۇرۇن جىمى ئىشلىرىنى كۆزىتىپ تۇرغۇچى، ھەممىنى ئىدارە قىلغۇچى زاتتۇر. |
| الرَّفِيقُ | ئەررەفىيق | ئىشلىرىدا مېھرىبانلىقنى ئالدىنقى ئورۇنغا قويغۇچى، بەندىلىرىگە شەپقەت-مېھرى بىلەن مۇئامىلە قىلغۇچى زاتتۇر. |
| القَرِيبُ | ئەل قەرىيب | ئىلمى، قۇدرىتى ۋە شەپقىتى بىلەن پۈتۈن خەلقىگە گۈرەن تومۇرلىرىدىنمۇ بەك يېقىن تۇرغۇچى زاتتۇر. |
| المُجِيبُ | ئەل مۇجىيب | دۇئا قىلغۇچىنىڭ دۇئاسىنى ۋە سورىغۇچىنىڭ تەلەپلىرىنى قوبۇل قىلغۇچى زاتتۇر. |
| المُقِيتُ | ئەل مۇقىيت | رىزىقلارنى ۋە ئوزۇقلۇقلارنى ياراتقان، ئۇلارنى يەتكۈزۈپ بېرىشكە كاپالەتلىك قىلغان زاتتۇر. |
| الحَسِيبُ | ئەل ھەسىيب | بەندىلىرىنىڭ دىن ۋە دۇنيالىق ئىشلىرىنىڭ ھەممىسىگە كۇپايە قىلغۇچى، بەندىلەرنىڭ ھېسابىنى ئالغۇچى زاتتۇر. |
| المُؤْمِنُ | ئەل مۇئمىن | پەيغەمبەرلىرىنىڭ ۋە مۈمىنلەرنىڭ راستچىللىقىنى تەستىقلىغۇچى، ئۇلارنى خاتىرجەم قىلغۇچى زاتتۇر. |
| المَنَّانُ | ئەل مەننان | بەندىلىرىگە ھېسابسىز نېمەتلەرنى ئاتا قىلغۇچى، سورىماستىن كۆپ بەرگۈچى زاتتۇر. |
| القُدُّوسُ | ئەل قۇددۇس | بارچە كەمچىلىكلەردىن پاك، ھەر تۈرلۈك ئەيىبلەردىن مۇكەممەل دەرىجىدە خالىي بولغان زاتتۇر. |
| الشَّافِي | ئەش شافىي | دىللار ۋە تەنلەرگە شىپالىق بەرگۈچى، قەلب كېسەللىكلىرى ۋە تەن ئاغرىقلىرىنى ساقايتقۇچى زاتتۇر. |
| الحَفِيظُ | ئەل ھەفىيز | ئاسمانلار ۋە زېمىندىكى پۈتۈن مەۋجۇداتنى قوغدىغۇچى، بەندىلەرنىڭ ئەمەللىرىنى ساقلىغۇچى زاتتۇر. |
| الحَافِظُ | ئەل ھافىز | مەخلۇقاتنى ھالاكەتتىن ساقلىغۇچى، مۈمىنلەرنى شەيتاننىڭ زىيانكەشلىكىدىن قوغدىغۇچى زاتتۇر. |
| الوَكِيلُ | ئەل ۋەكىيل | ئۆزىگە تەۋەككۈل قىلغانلارغا كۇپايە قىلغۇچى، پۈتۈن ئىشلار ئۆزىگە تاپشۇرۇلىدىغان ئىشەنچلىك زاتتۇر. |
| الخَالِقُ | ئەل خالىق | يوقلۇقتىن بارلىققا كەلتۈرگۈچى، ھەممە مەۋجۇداتنى مەلۇم ئۆلچەم بىلەن ياراتقۇچى زاتتۇر. |
| الخَلَّاقُ | ئەل خەللاق | پەيدا قىلىشتا چەكسىز قۇدرەتكە ئىگە، ھەمىشە يېڭىدىن مەۋجۇداتلارنى يارىتىپ تۇرغۇچى زاتتۇر. |
| البَارِئُ | ئەل بارىئ | مەخلۇقاتلارنى بىر-بىرىگە ئوخشىمايدىغان گۈزەل تەسۋىر ۋە شەكىللەردە ياراتقۇچى زاتتۇر. |
| الرَّبُّ | ئەر رەبب | پۈتۈن ئالەملەرنىڭ ئىگىسى، تەربىيەلىگۈچىسى، ھەر بىر مەخلۇققا لايىق رىزقىنى يەتكۈزۈپ تۇرغۇچى زاتتۇر. |
| العَظِيمُ | ئەل ئەزىم | شەنى، قۇدرىتى ۋە زاتىدا مۇتلەق چوڭلۇق ۋە كاتتىلىق ئىگىسى، ھەممىدىن ئەۋزەل بولغان زاتتۇر. |
| القَاهِرُ | ئەل قاھىر | ھەممىنى ئۆز ھۆكمىگە بويسۇندۇرغۇچى، ھېچ نەرسە ئۇنىڭ قۇدرىتىدىن چەتتە قالمايدىغان زاتتۇر. |
| القَهَّارُ | ئەل قەھھار | دۈشمەنلىرىنى خار قىلغۇچى، زالىملارنى يوقاتقۇچى ۋە جىمى مەۋجۇداتقا ھۆكۈمران زاتتۇر. |
| المُهَيْمِنُ | ئەل مۇھەيمىن | پۈتۈن كائىناتنى كۆزىتىپ تۇرغۇچى، ھەممىنى ئۆز قارمىقىدا تۇتقۇچى زاتتۇر. |
| الجَبَّارُ | ئەل جاببار | ئۈزۈلگەننى ئۇلىغۇچى، كۆڭۈللەرگە تەسەللى بەرگۈچى ۋە قۇدرىتى بىلەن كائىناتنى بويسۇندۇرغۇچى زاتتۇر. |
| المُتَكَبِّرُ | ئەل مۇتەكەببىر | ھەقىقىي بۈيۈكلۈك ۋە تەڭداشسىز ئۇلۇغۋارلىقنىڭ يېگانە ئىگىسى بولغان زاتتۇر. |
| العَزِيزُ | ئەل ئەزىز | مۇتلەق غالىب، ھېچقاچان مەغلۇپ بولمايدىغان، ئىززەت ۋە شەرەپنىڭ يېگانە ئىگىسى بولغان زاتتۇر. |
| الكَبِيرُ | ئەل كەبىير | زاتىدا، ئىسىم-سۈپەتلىرىدە ناھايىتى كاتتا ۋە ئۇلۇغ، ھەممە نەرسە ئۇنىڭ ئالدىدا كىچىك سانىلىدىغان زاتتۇر. |
