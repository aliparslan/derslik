(3) ئىنساننىڭ كېسەللىككە قارشى كۈچىنى ئاجىزلاشتۇرىدۇ ئىنساندىكى يۇقۇملۇق كېسەلگە قارشى تۇرىدىغان ئاق قان ئايلىنىشىنى ئىشلىمەس ھالغا كەلتۈرۈپ قويىدۇ (4 ) ھاراق ئىچىشكە ئادەتلەنگەن ئادەم سىل كېسىلىگە گىرىپتار بولىدۇ ئەگەر ئۇ ئۈچەي ياللۇغى كېسىلى بولۇپ قالسا، قۇتۇلۇش ئىمكانى بولمايدۇ

(5) ھ اراققا ئادەتلەنگەن ئادەمنىڭ ئوپېراتسىيىدە قۇتۇلۇش نىسبىتى ئىنتايىن ئاز بولىدۇ شۇڭلاشقا سۇغۇرتا شىركەتلىرى ھاراقكەشلەرنىڭ ھاياتىنى سۇغۇرتىغا ئالمايدۇ (6 ) دۇنيانىڭ ھەر قايسى جايلىرىدىكى دوختۇرخانىلاردا ناھايىتى ئىنچىكە تەكشۈرۈش لەرنى، ئېلىپ بارغاندىن كېيىن ساراڭلار دوختۇرخانىسىغا كىرگەن كېسەررن ىڭدىن كۆپرەكى ھاراق ئىچىدىغان ئادەمنىڭ بالىلىرى ئىكەنلىكى ئىسپاتلاندى (7 ) ھاراق يۈرەك بىلەن جىگەرنى كاردىن چىقىرىدۇ

(8) قان بېسىمى، شېكەر سىيىش ۋە يۈرەك كېسىلى بار ئادەمنىڭ ھاراق ئىچى شى ئۆز- ئۆزىنى ئۆلتۈرگەن بىلەن باراۋەردۇر چۈنكى مۇنداق قىلىش ئۆلۈمنى چاقىرىپ ئەكىلىد ۇ

(1) مائىدە سۈرىسى90 - - ئايەت قاراھ ەۋ ڭىنۇئ ىنىيىز ەدىققەھ (9 ) ھاراق بەزىلەرنىڭ گۇمان قىلغىنىدەك تاماق سىڭدۈرۈشكە ياردەم قىلمايدۇ، بەلكى ئۇ تاماق سىڭدۈرۈش ئورگانلىرىنىڭ پائالىيىتىگە توسالغۇ بولىدۇ ۋە ئاجىزلىتىدۇ ( ) ھاراقنىڭ ھېچقانداق ئوزۇقلۇق قىممىتى يوق شۇنى بىلىش كۇپايە قىلىدۇكى، بىر بوتۇلكا ھاراقنىڭ بىر قوشۇق گۈرۈچ كە چاغلىق ئوزۇقلۇق كۈچى يوق (

11) ھاراقكەش لەرنىڭ كۆپىنچىسى نامراتلىققا گىرىپتار بولىدۇ چۈنكى ئۇلار تاپقان پۇلىنى ھاراققا خەجلەيدۇ، ھاراق ئۈچۈن ئايالىنى ۋە بالىلىرىنى ئاچ قويىدۇ شۇنىڭ ب ىلەن ئائ ىلە ئەزالىرى ياخشى غىزالانمىغانلىقى ئۈچۈن ھەر خىل كېسەللىكلەرگە دۇچار بولىدۇ ( 12ى ) ت ببىي ستاتىستىكىلارنىڭ كۆرسىتىشىچە، جىنسىي كېسەللىككە دۇچار بولغانلارنىڭ كۆپ سانلىقى ھاراقنىڭ سەۋەبى بىلەن بولغان (
