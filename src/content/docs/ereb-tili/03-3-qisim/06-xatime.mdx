# 3-قىسىم خاتىمىسى: ئەرەب تىلىنىڭ ئاساسلىق گرامماتىكىلىق يىغىنچاق قائىدىلىرى

بۇ خاتىمە قىسمى پۈتكۈل ئۈچ قىسىم ئەرەب تىلى دەرسلىكىنىڭ جەۋھىرى ۋە لۇغەت مەسدەرلىرى، سۇنۇق كۆپلۈكلەر ھەمدە تۈرلىنىشتىن چەكلەنگەن ئىسىملارنىڭ مۇكەممەل قامۇسىدۇر.

---

## 1-مەزمۇن: تۈرلىنىشتىن چەكلەنگەن ئىسىملار (الْمَمْنُوعُ مِنَ الصَّرْفِ)

تۈرلىنىشتىن چەكلەنگەن ئىسىم تەنۋىننى (قوش ھەرىكەتنى) ۋە كەسرەنى (زىرنى) قوبۇل قىلمايدۇ. جەر (ئىگىلىك كېلىش) ھالىتىدە زىر ئورنىغا **زەبەر (فەتھە)** بىلەن ئىئرابلىنىدۇ.

### 1. بىرلا سەۋەب سەۋەبىدىن مەنئ قىلىنغانلار (عِلَّةٌ وَاحِدَةٌ)
بۇلار ئۆزى يالغۇز ئىككى سەۋەبنىڭ ئورنىدا ئۆتىدۇ:
1. **چېكىگە يەتكەن سۇنۇق كۆپلۈكلەر (صِيَغُ مُنْتَهَى الْجُمُوعِ):** سۇنۇق كۆپلۈك ئەلىفىدىن كېيىن ئىككى ھەرپ ياكى ئوتتۇرىسى سۇكۇنلۇق ئۈچ ھەرپ كەلگەن قېلىپلار:
   - **مَفَاعِلُ:** **مَسَاجِدُ** (مەسچىتلەر)، **مَدَارِسُ** (مەكتەپلەر)، **دَرَاهِمُ** (دەرھەملەر).
   - **مَفَاعِيلُ:** **مَفَاتِيحُ** (ئاچقۇچلار)، **مَصَابِيحُ** (چىراغلار)، **فَنَاجِينُ** (پىيالىلەر).
   - **فَوَاعِلُ:** **قَوَاعِدُ** (قائىدىلەر)، **شَوَارِعُ** (كوچىلار).
   - **فَعَائِلُ:** **رَسَائِلُ** (مەكتۇپلار)، **حَقَائِبُ** (سومكىلار).
2. **ئاخىرى سوزۇلما ئاياللىق ئەلىفى («ـَاءُ») بىلەن پۈتكەن ئىسىملار (أَلِفُ التَّأْنِيثِ الْمَمْدُودَةُ):**
   - **صَحْرَاءُ** (چۆل)، **حَمْرَاءُ** (قىزىل)، **بَيْضَاءُ** (ئاق)، **عُلَمَاءُ** (ئالىملار)، **أَصْدِقَاءُ** (دوستلار).
3. **ئاخىرى قىسقا ئاياللىق ئەلىفى («ـَى») بىلەن پۈتكەن ئىسىملار (أَلِفُ التَّأْنِيثِ الْمَقْصُورَةُ):**
   - **حُبْلَى** (ھامىلىدار)، **ذِكْرَى** (ئەسلەتمە)، **كُبْرَى** (ئەڭ چوڭ)، **جَرْحَى** (يارىدارلار).

---

### 2. ئىككى سەۋەب سەۋەبىدىن مەنئ قىلىنغانلار (عِلَّتَانِ)

#### 1) خاس نام بولۇش (الْعَلَمِيَّةُ) بىلەن باشقا بىر سەۋەب:
1. **ئاياللىق مەنىسى بولۇش (التَّأْنِيثُ):** مەيلى لەفزىدە ئاياللىق بەلگىسى بولسۇن ياكى مەنىدە بولسۇن:
   - **فَاطِمَةُ، خَدِيجَةُ، مَرْيَمُ، زَيْنَبُ، حَمْزَةُ، طَلْحَةُ**.
2. **ئەجەمىي (چەتئەلچە خاس نام) بولۇش (الْعُجْمَةُ):** 3 ھەرپتىن ئارتۇق بولغان غەيرىي ئەرەبچە ئىسىملار:
   - پەيغەمبەرلەرنىڭ ئىسىملىرى: **إِبْرَاهِيمُ، إِسْمَاعِيلُ، إِسْحَاقُ، يُوسُفُ**. *(ئۈچ ھەرپلىك ئوتتۇرىسى سۇكۇنلۇقلار تۈرلىنىدۇ: **نُوحٌ، لُوطٌ، هُودٌ**).*
   - شەھەر ۋە ئەل ناملىرى: **لَنْدَنُ، بَاكِسْتَانُ، بَغْدَادُ**.
3. **قوشما سۆز بولۇش (التَّرْكِيبُ الْمَزْجِيُّ):** ئىككى سۆز بىرىكىپ بىر بولۇپ كەتكەن:
   - **حَضْرَمَوْتُ، بَعْلَبَكُّ، مَعْدِيكَرِبُ**.
4. **ئاخىرى زىيادە ئەلىف ۋە نۇن («ـَانُ») بىلەن پۈتكەن بولۇش:**
   - **عُثْمَانُ، سَلْمَانُ، عَدْنَانُ، رَمَضَانُ**.
5. **پېئىل قېلىپىدا كەلگەن بولۇش (وَزْنُ الْفِعْلِ):**
   - **أَحْمَدُ** («أَفْعَلُ» قېلىپىدا)، **يَزِيدُ** («يَفْعِلُ» قېلىپىدا)، **يَشْكُرُ**.
6. **«فُعَلُ» ئۆلچىمىگە بۇراپ ئۆزگەرتىلگەن بولۇش (الْعَدْلُ):**
   - **عُمَرُ** (ئەسلى: عَامِرٌ)، **زُفَرُ**، **قُزَحُ**.

#### 2) سۈپەت بولۇش (الْوَصْفِيَّةُ) بىلەن باشقا بىر سەۋەب:
1. **«فَعْلَانُ» ئۆلچىمىدىكى سۈپەتلەر (ئاياللىقى «فَعْلَى» بولىدۇ):**
   - **غَضْبَانُ** (غەزەپلەنگەن)، **عَطْشَانُ** (ئۇسسىغان)، **جَوْعَانُ** (ئاچ قالغان)، **شَبْعَانُ** (توق).
2. **«أَفْعَلُ» ئۆلچىمىدىكى رەڭ ياكى ئاشۇرما سۈپەتلەر:**
   - **أَحْمَرُ** (قىزىل)، **أَسْوَدُ** (قارا)، **أَصْفَرُ** (سېرىق)، **أَحْسَنُ** (تېخىمۇ ياخشى)، **أَفْضَلُ** (ئەڭ ئەۋزەل).
3. **سانلارنىڭ «فُعَالُ» ۋە «مَفْعَلُ» قېلىپىدىكى تۈرلىرى:**
   - **أُحَادُ وَمَوْحَدُ** (بىردىن-بىردىن)، **ثُنَاءُ وَمَثْنَى** (ئىككىدىن-ئىككىدىن)، **ثُلَاثُ وَمَثْلَثُ** (ئۈچتىن-ئۈچتىن)، **رُبَاعُ وَمَرْبَعُ** (تۆتتىن-تۆتتىن).
4. **«أُخَرُ» سۆزى (باشقىلار — «أُخْرَى» نىڭ كۆپلۈكى):** **فَعِدَّةٌ مِنْ أَيَّامٍ أُخَرَ**.

### تۈرلىنىشنىڭ ئەسلىگە كېلىش ئەھۋاللىرى
تۈرلىنىشتىن چەكلەنگەن ئىسىملار تۆۋەندىكى ئىككى ھالەتتە قايتىدىن ئەسلىدىكىدەك **زىر (كەسرە)** قوبۇل قىلىپ تۈرلىنىدۇ:
1. ئالدىغا ئېنىقلىق ئارتىكلى **«الْـ»** كىرسە: **صَلَّيْتُ فِي الْمَسَاجِدِ**.
2. باشقا بىر سۆزگە **مۇزاف** بولۇپ كەلسە: **صَلَّيْتُ فِي مَسَاجِدِ الْمَدِينَةِ**.

## 3-مەزمۇن: پارچە كۆپلۈك (جَمْعُ التَّكْسِيرِ) تولۇق بايانى

پارچە ياكى سۇنۇق كۆپلۈك سۆزنىڭ بىرلىك شەكلى سۇنۇپ، ھەرپ قوشۇلۇش، كېمىيىش ياكى ھەرىكىتى ئۆزگىرىش بىلەن ياسىلىدىغان كۆپلۈكتۇر. ئىككى چوڭ كاتېگورىيەگە ئايرىلىدۇ:

### 1. ئازلىق كۆپلۈك (جَمْعُ الْقِلَّةِ)
3 دىن 10 غىچە بولغان ئاز مىقدارنى ئىپادىلەيدۇ. تۆت خىل ئۆلچىمى بار:
1. **أَفْعُلٌ:** **نَفْسٌ** ← **أَنْفُسٌ**، **عَيْنٌ** ← **أَعْيُنٌ**، **شَهْرٌ** ← **أَشْهُرٌ**.
2. **أَفْعَالٌ:** **قَلَمٌ** ← **أَقْلَامٌ**، **وَلَدٌ** ← **أَوْلَادٌ**، **صَاحِبٌ** ← **أَصْحَابٌ**.
3. **أَفْعِلَةٌ:** **طَعَامٌ** ← **أَطْعِمَةٌ**، **مِثَالٌ** ← **أَمْثِلَةٌ**، **سُؤَالٌ** ← **أَسْئِلَةٌ**.
4. **فِعْلَةٌ:** **فَتًى** ← **فِتْيَةٌ**، **صَبِيٌّ** ← **صِبْيَةٌ**، **أَخٌ** ← **إِخْوَةٌ**.

### 2. كۆپلۈك كۆپلۈك (جَمْعُ الْكَثْرَةِ)
3 دىن باشلاپ چەكسىز چوڭ سانلارغىچە ئىپادىلەيدۇ. ئەڭ مەشھۇر 16 ئۆلچىمى:
1. **فُعْلٌ:** **أَحْمَرُ** ← **حُمْرٌ**، **أَبْيَضُ** ← **بِيضٌ**.
2. **فُعُلٌ:** **كِتَابٌ** ← **كُتُبٌ**، **رَسُولٌ** ← **رُسُلٌ**، **مَدِينَةٌ** ← **مُدُنٌ**.
3. **فُعَلٌ:** **غُرْفَةٌ** ← **غُرَفٌ**، **صُورَةٌ** ← **صُوَرٌ**، **قَرْيَةٌ** ← **قُرًى**.
4. **فِعَلٌ:** **قِطْعَةٌ** ← **قِطَعٌ**، **فِرْقَةٌ** ← **فِرَقٌ**، **حِكْمَةٌ** ← **حِكَمٌ**.
5. **فُعَلَةٌ:** **كَافِرٌ** ← **كَفَرَةٌ**، **فَاجِرٌ** ← **فَجَرَةٌ**.
6. **فَعَلَةٌ:** **طَالِبٌ** ← **طَلَبَةٌ**، **سَاحِرٌ** ← **سَحَرَةٌ**، **حَافِظٌ** ← **حَفَظَةٌ**.
7. **فَعْلَى:** **جَرِيحٌ** ← **جَرْحَى**، **مَرِيضٌ** ← **مَرْضَى**، **قَتِيلٌ** ← **قَتْلَى**.
8. **فِعَلَةٌ:** **قِرْدٌ** ← **قِرَدَةٌ**، **دُبٌّ** ← **دِبَبَةٌ**.
9. **فُعَّلٌ:** **سَاجِدٌ** ← **سُجَّدٌ**، **رَاكِعٌ** ← **رُكَّعٌ**.
10. **فُعَّالٌ:** **كَاتِبٌ** ← **كُتَّابٌ**، **تَاجِرٌ** ← **تُجَّارٌ**، **طَالِبٌ** ← **طُلاَّبٌ**.
11. **فِعَالٌ:** **جَبَلٌ** ← **جِبَالٌ**، **رَجُلٌ** ← **رِجَالٌ**، **ثَوْبٌ** ← **ثِيَابٌ**.
12. **فُعُولٌ:** **قَلْبٌ** ← **قُلُوبٌ**، **عِلْمٌ** ← **عُلُومٌ**، **نَجْمٌ** ← **نُجُومٌ**.
13. **فِعْلَانٌ:** **نَارٌ** ← **نِيرَانٌ**، **جَارٌ** ← **جِيرَانٌ**، **صَبِيٌّ** ← **صِبْيَانٌ**.
14. **فُعْلَانٌ:** **بَلَدٌ** ← **بُلْدَانٌ**، **قَمِيصٌ** ← **قُمْصَانٌ**، **شَابٌّ** ← **شُبَّانٌ**.
15. **فُعَلَاءُ:** **عَالِمٌ** ← **عُلَمَاءُ**، **أَمِيرٌ** ← **أُمَرَاءُ**، **شَاعِرٌ** ← **شُعَرَاءُ**.
16. **أَفْعِلَاءُ:** **غَنِيٌّ** ← **أَغْنِيَاءُ**، **صَدِيقٌ** ← **أَصْدِقَاءُ**، **نَبِيٌّ** ← **أَنْبِيَاءُ**.

<Aside type="tip" title="ئەرەب تىلىنىڭ چەكسىز پىشىپ يېتىلىشى">
بۇ قائىدىلەر «ئەرەب تىلى دەرسلىكى گرامماتىكا قائىدىلىرى» ئەسىرىنىڭ بارلىق تۈرلىرىنى تولۇق ئۆز ئىچىگە ئالغان بولۇپ، ئوقۇرمەننى قۇرئان كەرىم ۋە ھەدىس شەرىپنىڭ، شۇنداقلا كلاسسىك ئەدەبىياتنىڭ تىل بايلىقىنى توغرا، خاتاسىز چۈشىنىش ئىقتىدارىغا ئىگە قىلىدۇ.
</Aside>
